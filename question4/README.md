# 问题四：考虑收缩的热湿耦合数值求解

本目录给出问题四从附件读取、移动边界 Crank–Nicolson 求解、临界时刻定位、收敛检验、对照实验、题目表格和中文论文图的完整代码与结果。

## 核心结果

- 按“药材内部所有位置的水分浓度均低于 0.15 kg/kg”判定，考虑真实收缩时的临界烘干时刻为 **51.0939 h**，对应严格整数秒为 **183939 s**。
- 临界时刻药材半径为 **1.2000 cm**，最大水分浓度为 **0.150000 kg/kg**，最湿点在中心；表面为 **0.052620 kg/kg**，截面平均值为 **0.118408 kg/kg**。
- 在物性、环境和数值方法均相同，仅固定半径为 2 cm 的对照模型中，临界时刻为 **129.8556 h**。收缩使预测时间减少 **78.7617 h（60.65%）**。
- N=200 与 N=400 的达标时刻相差 9.0435 s（相对差 4.92×10^-5）；在 N=400 下将时间步从 0.5 s 减至 0.25 s，只相差 0.000366 s。

## 一键复现

在本目录运行：

```text
python code/run_all_q4.py
```

完整复现包含约 280 万个 Crank–Nicolson 时间步，预计耗时约 35–45 min。只检查环境与核心方程可运行：

```text
python code/q4_solver.py --smoke
```

若正式场文件已经存在，仅重新生成表格、图片和验收报告：

```text
python code/run_all_q4.py --reuse-results
```

脚本会自动处理 Windows 中文长路径，无须手工映射盘符。

## 目录说明

- `data/`：题目附件 1、附件 2 和 result4 模板。
- `code/q4_solver.py`：参考坐标下的移动边界有限体积 Crank–Nicolson 求解器。
- `code/export_q4_results.py`：生成题目规定的 `result4.xlsx`、论文表和 MAT/CSV 结果。
- `code/make_q4_figures.py`：生成 raw/process/result 三类中文论文候选图。
- `code/verify_q4.py`：自动检查阈值、收敛、数值稳定性和表格结构。
- `results/q4_verification_report.json`：机器验收报告。
- `问题四_结果说明.md`：可直接交给论文手组织正文的模型与结果说明。

`result4.xlsx` 中固定物理位置超出当前收缩半径时按题意留空，最右侧另设“药材表面”列记录移动表面的数值。
