# 最终结果提交目录

本目录将四问结果分为“题目要求的最终提交表格”和“论文支撑结果”两类。最终上传答题系统时，核心结果是 `01_submission_tables/` 中的四个 Excel 文件；`02_paper_support/` 用于论文制表、数值检验和队内复核。

## 1. 最终提交表格

| 文件 | 对应问题 | 内容 |
|---|---|---|
| `result1.xlsx` | 问题一 | 预热阶段温度场与水分场的完整 CN 正式结果 |
| `result2.xlsx` | 问题二 | 前 3 h 变物性热湿耦合完整结果 |
| `result3.xlsx` | 问题三 | 烘干至全部位置低于阈值的完整水分结果 |
| `result4.xlsx` | 问题四 | 考虑半径收缩后的完整水分结果，超出当前半径的位置留空 |

## 2. 论文支撑结果

### q1

- 指定时刻温度和水分表：直接用于问题一正文结果表。
- 边界插值比较、CN 收敛性和差异来源量化：用于数值方法选择与误差分析。
- CN/BE 校验摘要和复现清单：用于复核正式结果来源。

### q2

- 温度表与水分表：用于问题二正文表格。
- 网格收敛性、非线性求解器比较和验证摘要：用于模型检验。

### q3

- `q3_result_table.*`：问题三论文精简结果表。
- `q3_final_summary.xlsx`、收敛性、诊断和验证报告：用于临界时刻与数值可靠性说明。
- `q3_repro_manifest.json`：正式结果复现清单。

### q4

- `q4_result_table.*`：问题四论文精简结果表。
- `q4_summary.*`：收缩模型的关键结论汇总。
- 收敛性、诊断、验证报告和复现清单：用于问题四模型检验。

## 3. 未收入的文件

- 后向欧拉完整结果及 `result1_BE.xlsx`：仅作为问题一方法对照，不作为正式答案。
- 与 `result1.xlsx` 内容重复的 `result1_CN.xlsx`：避免重复提交。
- 大型 NPZ/MAT 场文件：属于计算缓存或底层原始数组，不是最终答题表。
- 环境数据和半径数据副本：属于输入或派生输入，不是模型输出。
- 与 `result3.xlsx` 重复的 `q3_full_result.xlsx`：避免重复提交。
