# 最终代码目录

本目录是 A 题问题一至问题四的最终代码归档。所有源文件均来自各问题的正式 `code` 目录，并保留函数级中文说明。

## 结构

```text
final_code/
├─ q1/                    问题一：求解、数值方法对照及论文绘图
├─ q2/                    问题二：变物性热湿耦合求解
├─ q3/                    问题三：求解、导出、绘图与验证
├─ q4/                    问题四：收缩模型求解、导出、绘图与验证
└─ requirements.txt       Python 依赖
```

## 主要运行入口

| 问题 | 入口文件 | 说明 |
|---|---|---|
| 问题一 | `q1/q1_cn_comparison.py` | Crank--Nicolson 正式求解、后向欧拉对照与数值验证 |
| 问题二 | `q2/q2_solver.py` | 变物性热湿耦合模型求解 |
| 问题三 | `q3/run_all_q3.py` | 一键完成求解、导出、绘图和验证 |
| 问题四 | `q4/run_all_q4.py` | 一键完成求解、导出、绘图和验证 |

部分程序仍按原项目结构读取附件和结果文件，因此进行完整复现时建议在仓库原有的 `question1` 至 `question4` 目录运行对应入口。本目录主要用于最终提交、审阅和代码归档。
